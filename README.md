# Murtadha Najem (مرتضى نجم)

AI & Data Engineer at Kapita Research in Baghdad. I build the pipelines that take raw data from Iraqi sources, much of it in Arabic, to clean datasets, dashboards and research findings.

Outside work I build small tools, mostly in the browser and mostly for Arabic readers.

## Selected work

| Project | What it does |
|---|---|
| [iraq-etl-pipeline](https://github.com/murtadha203/iraq-etl-pipeline) | Collected and cleaned 100,000+ Iraqi job postings from 15+ sources: APIs, websites and Telegram channels |
| [iraq-service-atlas-dashboard](https://github.com/murtadha203/iraq-service-atlas-dashboard) | Arabic dashboard of digitally mapped services across Iraq, on 10 km and 1 km grids |
| [scraping-skill](https://github.com/murtadha203/scraping-skill) | A Claude Code skill that teaches a way of thinking about web scraping, with an encyclopedia of 170 tools |
| [browser-use-skill](https://github.com/murtadha203/browser-use-skill) | Routes each browser task to the fastest tool instead of a screenshot per click |
| [hams](https://github.com/murtadha203/hams) | Chat with nearby devices by sound, with no internet: a near-ultrasonic modem in the browser |
| [babel-arabic](https://github.com/murtadha203/babel-arabic) | The Library of Babel in Arabic: every book that can be written in Arabic letters |
| [hierarchical-llm-5g-control](https://github.com/murtadha203/hierarchical-llm-5g-control) | 5G/6G network control: fast deterministic agents for the radio, a safety-guarded LLM for policy |
